# Datasets

Raw datasets are **not redistributed** in this repository (they are covered by
their own upstream licenses). This document lists every file the code expects
under `data/` and how to obtain or regenerate it. Place the prepared files in
this directory before running experiments.

| File | Persona / task | Source |
|------|----------------|--------|
| `sycophancy.csv` | Sycophancy | Anthropic model-written evals — sycophancy splits (Perez et al., 2022). https://github.com/anthropics/evals |
| `myopic-reward.jsonl` | Myopic reward | Anthropic model-written persona evals — `myopic-reward.jsonl`. https://github.com/anthropics/evals |
| `conscientiousness.jsonl` / `persona_conscientiousness.csv` | Conscientiousness | Anthropic model-written persona evals — `conscientiousness.jsonl`. https://github.com/anthropics/evals |
| `truthfulqa_logprob.csv` | Hallucination (TruthfulQA) | Generated by `analysis/prep_truthfulqa.py` from the HuggingFace `truthful_qa` (generation) dataset (Lin et al., 2022). |
| `hallucination.csv` / `hallucination_mc.csv` | Hallucination (HaluEval) | Derived from HaluEval (Li et al., 2023). https://github.com/RUCAIBox/HaluEval |

## Expected schemas

- **Sycophancy** (`sycophancy.csv`): columns `question`, `answer_matching_behavior`,
  `answer_not_matching_behavior` (the `(A)`/`(B)` style Anthropic format).
- **TruthfulQA** (`truthfulqa_logprob.csv`): columns `question`, `true_answer`,
  `incorrect_answers` (a JSON-serialized list). Produced directly by the prep script.

## Regenerating TruthfulQA

```bash
python analysis/prep_truthfulqa.py     # writes data/truthfulqa_logprob.csv
```

## Notes

- The Anthropic eval files are JSONL; the sycophancy CSV used here is a flattened
  version of those question/answer pairs. Reformat the upstream JSONL to the
  schema above if you are rebuilding from scratch.
- Please cite the original dataset papers (Anthropic evals, TruthfulQA, HaluEval)
  when using these resources.
